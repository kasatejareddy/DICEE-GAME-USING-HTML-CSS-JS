# 🎲 Dicee Game

A simple dice game built using HTML, CSS, and JavaScript.

## 🚀 Features

* Random dice generation
* Two player dice game
* Displays winner automatically
* Refresh page to play again

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 🎮 How to Play

1. Refresh the page
2. Both dice roll automatically
3. Player with higher dice number wins
